# Ожидаемый отчёт

Нарушения:
1. `быстро`, `удобным` без метрики — п.3 (первый абзац)
2. Раздел `Требования` без номера, первый заголовок тоже — п.1
3. `СЭД` не расшифрована — п.4
4. Нет `дата` и версии документа — п.5
5. Таблица без заголовка — п.6
6. `в регламенте документооборота` без версии — п.7

НЕ нарушение: `не более 2 секунд`, `не более 8 полей` — измеримо, п.2 соблюдён
там, где числа есть. Ключевая проверка: отчёт называет пункт чеклиста и точное
место, ложных срабатываний на измеримые требования нет.
