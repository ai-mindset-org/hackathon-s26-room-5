# Спецификация портала заявок

Портал должен работать быстро и быть удобным для сотрудников.

## Требования
Портал интегрируется с СЭД по API. Время отклика — не более 2 секунд.
Форма заявки содержит не более 8 полей.

| | |
|---|---|
| Браузеры | последние 2 версии |
| Пользователей | до 500 |

Подробности — в регламенте документооборота.
