# Ожидаемый результат обезличивания

Текст, где: Пётр Крылов → PERSON-1 (оба вхождения — одним плейсхолдером!),
Анна Соловьёва → PERSON-2, телефон → PHONE-1, email → EMAIL-1,
добавочный → EXT-1. `INV-0042` и дата — НЕ трогаются (не персональные данные).

Плюс `mapping.json` для обратного маппинга: {"PERSON-1": "Пётр Крылов", ...} —
прогон текста через mapping восстанавливает оригинал байт в байт.

Ключевая проверка: повторное вхождение того же человека получило ТОТ ЖЕ
плейсхолдер; идентификатор сервера не обезличен.
