# Ожидаемый отчёт

Нарушение: Таймаут строкой вместо числа.

Место: первый найденный litellm_params.timeout.

Цитата: `timeout: "120s"  (было число: 120)`

Что не так: timeout задан строкой вместо числа секунд — YAML синтаксически валиден, но litellm ждёт число; типовая «тихая» ошибка, которая не падает на этапе парсинга конфига

Ключевая проверка: инструмент должен указать именно это место и процитировать именно это значение — не общий «конфиг не соответствует».
