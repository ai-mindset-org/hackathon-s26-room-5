# Ожидаемый отчёт

Нарушение: Обращение к провайдеру по http вместо https (П6).

Место: models.*.providers.* → api_base.

Цитата: `http://openrouter.ai/api/v1`

Что не так: хост openrouter.ai/api/v1 указан по http — ключ и запросы уходят незашифрованными. Правило П6.

Ключевая проверка: инструмент должен указать именно это место и процитировать именно это значение — не общий «конфиг не соответствует».
