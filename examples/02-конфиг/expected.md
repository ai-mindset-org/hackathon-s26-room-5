# Ожидаемый отчёт

1. `DB_URL` — пароль открытым текстом в файле · правило 1
2. `BIND_HOST=0.0.0.0` без пометки «публичный» · правило 2
3. `DEBUG=true` · правило 3
4. Порт `8912` без комментария, что на нём живёт · правило 4

НЕ нарушение: `API_TOKEN_FILE` — ссылка на файл вне репо, правило 1 соблюдено.
Ключевая проверка: токен-файл не пойман как «секрет» (ложных срабатываний нет).
