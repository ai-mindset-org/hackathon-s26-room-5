# Как запустить приложение

Нужен Python 3.11+ и `pyyaml`. Больше ничего.

```bash
pip3 install pyyaml
python3 app.py          # браузер откроется сам на localhost:8765
```

Сервер слушает только 127.0.0.1: файлы читаются с вашей машины, наружу
ничего не уходит.

---

## Зачем оно, если есть раннер

`python3 -m runner` отвечает на вопрос комнаты: «прошло N из M». Заказчику
нужен другой ответ — что именно не так в **его** файле и где это лежит.
Отсюда три вещи, которых в терминале нет.

**Перетащить свой артефакт.** Конфиг, спецификацию, две таблицы или текст —
не заводя пример в репозитории. Инструмент сам выберет, чем это проверять.

**Увидеть находку в файле.** Вкладка «Инспект»: исходник со строками, места
находок подсвечены, клик по находке ведёт к строке.

**Проверить инструмент на незнакомом файле.** Генератор собирает артефакт,
где часть строк — дефекты, а часть — приманки, на которые срабатывать нельзя.
Что заложено, известно заранее, поэтому видно: поймано, пропущено или поднята
ложная тревога.

Модули, ядро и приёмка — те же самые. Приложение ничего своего не считает,
оно показывает то, что вернули `core` и `runner`.

## Что на экране

| Место | Что там |
|---|---|
| Слева | все примеры из `examples/`, плашка = статус официального раннера |
| Генератор | собрать файл с дефектами и сразу проверить |
| Свои файлы | перетащить артефакт и чеклист |
| Вердикт сверху | «есть что исправить: N нарушений» или «замечаний нет» |
| Вкладки | нарушения · вопросы · инспект · проверено и норма · выданные файлы · приёмка |
| Кнопка | скачать полный отчёт `.md` |

Выгрузка в markdown содержит всё, что на экране: вердикт, сводку, каждую
находку с цитатой, что признано нормой, чего машина не проверяла, сверку
с ожиданиями, выданные файлы и исходники построчно с пометками.

## Самопроверка

```bash
python3 selfcheck.py                      # приёмка + 10 генераций на вид
python3 selfcheck.py --runs 100           # глубже: 400 прогонов
python3 selfcheck.py --kind pii --seed 2  # разобрать один случай
```

Печатает три вида проблем: **пропуск** (дефект заложен, инструмент промолчал),
**ложная тревога** (сработал на приманке — это хуже пропуска) и **сверх плана**
(нашёл незапланированное; не всегда ошибка). У каждой строки — команда для
воспроизведения.

Самопроверка уже нашла и помогла починить несколько настоящих багов:
обезличиватель брал файл правил вместо артефакта; он же не брался за текст,
где люди названы только фамилией; заголовок файла засчитывался как комментарий
к порту, и порт без пояснения проходил молча.
