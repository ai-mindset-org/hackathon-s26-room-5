`litellm-config.yaml` эти правила почти не срабатывают.

## test-values.yaml (tensorzero-формат)

```
python3 tools/config-mutator/generate.py --config "examples/05-конфиг-платформы-агентов/input/test-values.yaml" --out-prefix 20
```

**0/6 — ломалка не смогла сломать ни одного места.** Её паттерны
(`model_name:`, `custom_llm_provider:` — YAML-синтаксис) не совпадают с
TOML-синтаксисом tensorzero (`model_name = "..."`). Ломалка сама написана
под litellm-формат, не под tensorzero — отдельная, ещё не сделанная задача.

## Вывод

Оба инструмента комнаты (чекер и ломалка) сейчас закрывают только
tensorzero/litellm-YAML-часть неполно и в разных углах: чекер почти не
видит litellm-config.yaml, ломалка вообще не видит tensorzero.toml. Ни
один из двух реальных форматов конфига Дениса не покрыт целиком ни одним
инструментом. Фиксируется как факт для комнаты — доработка вне рамок этого
прогона.
